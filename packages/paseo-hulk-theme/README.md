# paseo-hulk-theme

Hulk for [Paseo](https://paseo.sh), ported from the Obsidian theme [`pgalliford/Obsidian-theme-Incredible-Hulk`](https://github.com/pgalliford/Obsidian-theme-Incredible-Hulk) by pgalliford.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-hulk-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Hulk** for the dark variant or **Hulk Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
