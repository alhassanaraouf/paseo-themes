# paseo-gdct-dark-theme

GDCT Dark for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bcdavasconcelos/Obsidian-GDCT_Dark`](https://github.com/bcdavasconcelos/Obsidian-GDCT_Dark) by bcdavasconcelos.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-gdct-dark-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **GDCT Dark** for the dark variant or **GDCT Dark Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
