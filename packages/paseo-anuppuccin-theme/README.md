# paseo-anuppuccin-theme

AnuPpuccin for [Paseo](https://paseo.sh), ported from the Obsidian theme [`anubisnekhet/AnuPpuccin`](https://github.com/anubisnekhet/AnuPpuccin) by anubisnekhet.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-anuppuccin-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **AnuPpuccin** for the dark variant or **AnuPpuccin Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
