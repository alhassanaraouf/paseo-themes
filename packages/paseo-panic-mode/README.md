# paseo-panic-mode

Panic Mode for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bcdavasconcelos/Obsidian-Panic_Mode`](https://github.com/bcdavasconcelos/Obsidian-Panic_Mode) by bcdavasconcelos.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-panic-mode
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Panic Mode** for the dark variant or **Panic Mode Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
