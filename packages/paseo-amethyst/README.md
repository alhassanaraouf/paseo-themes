# paseo-amethyst

Amethyst for [Paseo](https://paseo.sh), ported from the Obsidian theme [`cotemaxime/obsidian-amethyst`](https://github.com/cotemaxime/obsidian-amethyst) by cotemaxime.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-amethyst
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Amethyst** for the dark variant or **Amethyst Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
