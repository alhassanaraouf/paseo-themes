# paseo-discordian

Discordian for [Paseo](https://paseo.sh), ported from the Obsidian theme [`radekkozak/discordian`](https://github.com/radekkozak/discordian) by radekkozak.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-discordian
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Discordian** for the dark variant or **Discordian Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
