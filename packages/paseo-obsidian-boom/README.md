# paseo-obsidian-boom

Obsidian Boom for [Paseo](https://paseo.sh), ported from the Obsidian theme [`sainadhx/obsidian-boom`](https://github.com/sainadhx/obsidian-boom) by sainadhx.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidian-boom
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsidian Boom** for the dark variant or **Obsidian Boom Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
