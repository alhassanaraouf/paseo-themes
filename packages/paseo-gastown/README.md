# paseo-gastown

Gastown for [Paseo](https://paseo.sh), ported from the Obsidian theme [`dogwaddle/obsidian-gastown-theme.md`](https://github.com/dogwaddle/obsidian-gastown-theme.md) by dogwaddle.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-gastown
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Gastown** for the dark variant or **Gastown Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
