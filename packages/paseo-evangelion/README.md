# paseo-evangelion

evangelion for [Paseo](https://paseo.sh), ported from the Obsidian theme [`xero/evangelion.obsidian`](https://github.com/xero/evangelion.obsidian) by xero.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-evangelion
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **evangelion** for the dark variant or **evangelion Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
