# paseo-dune

Dune for [Paseo](https://paseo.sh), ported from the Obsidian theme [`jopp-gh/Obsidian-Dune84`](https://github.com/jopp-gh/Obsidian-Dune84) by jopp-gh.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-dune
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Dune** for the dark variant or **Dune Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
