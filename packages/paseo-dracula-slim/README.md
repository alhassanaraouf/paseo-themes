# paseo-dracula-slim

Dracula Slim for [Paseo](https://paseo.sh), ported from the Obsidian theme [`blackwew/Dracula-Slim`](https://github.com/blackwew/Dracula-Slim) by blackwew.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-dracula-slim
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Dracula Slim** for the dark variant or **Dracula Slim Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
