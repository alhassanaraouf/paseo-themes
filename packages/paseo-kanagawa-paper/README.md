# paseo-kanagawa-paper

Kanagawa Paper for [Paseo](https://paseo.sh), ported from the Obsidian theme [`sspaeti/obsidian_kanagawa_paper`](https://github.com/sspaeti/obsidian_kanagawa_paper) by Simon Späti.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-kanagawa-paper
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Kanagawa Paper** for the dark variant or **Kanagawa Paper Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
