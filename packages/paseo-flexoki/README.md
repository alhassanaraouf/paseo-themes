# paseo-flexoki

Flexoki for [Paseo](https://paseo.sh), ported from the Obsidian theme [`kepano/flexoki-obsidian`](https://github.com/kepano/flexoki-obsidian) by kepano.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-flexoki
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Flexoki** for the dark variant or **Flexoki Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
