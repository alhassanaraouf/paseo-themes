# paseo-emerald

Emerald for [Paseo](https://paseo.sh), ported from the Obsidian theme [`gracejoseph1236/obsidian-emerald`](https://github.com/gracejoseph1236/obsidian-emerald) by gracejoseph1236.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-emerald
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Emerald** for the dark variant or **Emerald Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
