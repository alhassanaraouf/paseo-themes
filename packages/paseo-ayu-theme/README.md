# paseo-ayu-theme

Ayu for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bcdavasconcelos/Obsidian-Ayu`](https://github.com/bcdavasconcelos/Obsidian-Ayu) by bcdavasconcelos.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-ayu-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Ayu** for the dark variant or **Ayu Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
