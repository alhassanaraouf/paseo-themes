# paseo-lyt-mode-theme

LYT Mode for [Paseo](https://paseo.sh), ported from the Obsidian theme [`nickmilo/LYT-Mode`](https://github.com/nickmilo/LYT-Mode) by nickmilo.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-lyt-mode-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **LYT Mode** for the dark variant or **LYT Mode Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
