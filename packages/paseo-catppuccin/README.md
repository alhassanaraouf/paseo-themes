# paseo-catppuccin

Catppuccin for [Paseo](https://paseo.sh), ported from the Obsidian theme [`catppuccin/obsidian`](https://github.com/catppuccin/obsidian) by catppuccin.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-catppuccin
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Catppuccin** for the dark variant or **Catppuccin Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
