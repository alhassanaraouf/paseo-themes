# paseo-cardstock-theme

Cardstock for [Paseo](https://paseo.sh), ported from the Obsidian theme [`cassidoo/cardstock`](https://github.com/cassidoo/cardstock) by cassidoo.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-cardstock-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Cardstock** for the dark variant or **Cardstock Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
