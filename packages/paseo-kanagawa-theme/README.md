# paseo-kanagawa-theme

Kanagawa for [Paseo](https://paseo.sh), ported from the Obsidian theme [`sspaeti/obsidian_kanagawa`](https://github.com/sspaeti/obsidian_kanagawa) by Simon Späti.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-kanagawa-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Kanagawa** for the dark variant or **Kanagawa Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
