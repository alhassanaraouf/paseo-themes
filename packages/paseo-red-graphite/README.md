# paseo-red-graphite

Red Graphite for [Paseo](https://paseo.sh), ported from the Obsidian theme [`seanwcom/Red-Graphite-for-Obsidian`](https://github.com/seanwcom/Red-Graphite-for-Obsidian) by seanwcom.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-red-graphite
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Red Graphite** for the dark variant or **Red Graphite Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
