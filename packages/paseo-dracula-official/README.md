# paseo-dracula-official

Dracula Official for [Paseo](https://paseo.sh), ported from the Obsidian theme [`dracula/obsidian`](https://github.com/dracula/obsidian) by dracula.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-dracula-official
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Dracula Official** for the dark variant or **Dracula Official Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
