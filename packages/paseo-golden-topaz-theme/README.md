# paseo-golden-topaz-theme

Golden Topaz for [Paseo](https://paseo.sh), ported from the Obsidian theme [`shaggyfeng/obsidian-Golden-Topaz-theme`](https://github.com/shaggyfeng/obsidian-Golden-Topaz-theme) by shaggyfeng.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-golden-topaz-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Golden Topaz** for the dark variant or **Golden Topaz Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
