# paseo-obsidianotion

Obsidianotion for [Paseo](https://paseo.sh), ported from the Obsidian theme [`diegoeis/obsidianotion`](https://github.com/diegoeis/obsidianotion) by Diego Eis.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidianotion
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsidianotion** for the dark variant or **Obsidianotion Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
