# paseo-obsidian-gruvbox

Obsidian gruvbox for [Paseo](https://paseo.sh), ported from the Obsidian theme [`insanum/obsidian_gruvbox`](https://github.com/insanum/obsidian_gruvbox) by insanum.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidian-gruvbox
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsidian gruvbox** for the dark variant or **Obsidian gruvbox Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
