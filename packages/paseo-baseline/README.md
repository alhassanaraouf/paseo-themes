# paseo-baseline

Baseline for [Paseo](https://paseo.sh), ported from the Obsidian theme [`svnaxis/obsidian-baseline`](https://github.com/svnaxis/obsidian-baseline) by Alexis C.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-baseline
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Baseline** for the dark variant or **Baseline Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
