# paseo-everforest-enchanted

Everforest Enchanted for [Paseo](https://paseo.sh), ported from the Obsidian theme [`fireisgood/obsidian-everforest-enchanted`](https://github.com/fireisgood/obsidian-everforest-enchanted) by fireisgood.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-everforest-enchanted
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Everforest Enchanted** for the dark variant or **Everforest Enchanted Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
