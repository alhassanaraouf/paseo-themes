# paseo-firefly

Firefly for [Paseo](https://paseo.sh), ported from the Obsidian theme [`lazercaveman/obsidian-firefly-theme`](https://github.com/lazercaveman/obsidian-firefly-theme) by lazercaveman.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-firefly
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Firefly** for the dark variant or **Firefly Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
