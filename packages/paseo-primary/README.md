# paseo-primary

Primary for [Paseo](https://paseo.sh), ported from the Obsidian theme [`primary-theme/obsidian`](https://github.com/primary-theme/obsidian) by primary-theme.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-primary
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Primary** for the dark variant or **Primary Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
