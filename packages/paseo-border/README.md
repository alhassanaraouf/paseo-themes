# paseo-border

Border for [Paseo](https://paseo.sh), ported from the Obsidian theme [`akifyss/obsidian-border`](https://github.com/akifyss/obsidian-border) by akifyss.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-border
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Border** for the dark variant or **Border Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
