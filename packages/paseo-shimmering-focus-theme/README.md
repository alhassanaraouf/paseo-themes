# paseo-shimmering-focus-theme

Shimmering Focus for [Paseo](https://paseo.sh), ported from the Obsidian theme [`chrisgrieser/shimmering-focus`](https://github.com/chrisgrieser/shimmering-focus) by Chris Grieser.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-shimmering-focus-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Shimmering Focus** for the dark variant or **Shimmering Focus Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
