# paseo-shiba-inu-theme

Shiba Inu for [Paseo](https://paseo.sh), ported from the Obsidian theme [`faroukx/Obsidian-shiba-inu-theme`](https://github.com/faroukx/Obsidian-shiba-inu-theme) by faroukx.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-shiba-inu-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Shiba Inu** for the dark variant or **Shiba Inu Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
