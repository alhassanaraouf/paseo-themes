# paseo-obsidian-nord

Obsidian Nord for [Paseo](https://paseo.sh), ported from the Obsidian theme [`insanum/obsidian_nord`](https://github.com/insanum/obsidian_nord) by insanum.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidian-nord
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsidian Nord** for the dark variant or **Obsidian Nord Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
