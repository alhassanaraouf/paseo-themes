# paseo-dark-graphite

Dark Graphite for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bcdavasconcelos/Obsidian-Graphite`](https://github.com/bcdavasconcelos/Obsidian-Graphite) by bcdavasconcelos.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-dark-graphite
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Dark Graphite** for the dark variant or **Dark Graphite Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
