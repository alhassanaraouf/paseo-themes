# paseo-cybertron-theme

Cybertron for [Paseo](https://paseo.sh), ported from the Obsidian theme [`nickmilo/Cybertron`](https://github.com/nickmilo/Cybertron) by nickmilo.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-cybertron-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Cybertron**.

## Themes

This plugin contributes one `dark`-mode `addTheme` variant derived from the upstream Obsidian palette.
