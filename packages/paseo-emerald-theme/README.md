# paseo-emerald-theme

Emerald for [Paseo](https://paseo.sh), ported from the Obsidian theme [`gracejoseph1236/obsidian-emerald`](https://github.com/gracejoseph1236/obsidian-emerald) by gracejoseph1236.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-emerald-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Emerald**.

## Themes

This plugin contributes one `dark`-mode `addTheme` variant derived from the upstream Obsidian palette.
