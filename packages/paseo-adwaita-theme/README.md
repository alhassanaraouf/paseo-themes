# paseo-adwaita-theme

Adwaita for [Paseo](https://paseo.sh), ported from the Obsidian theme [`birneee/obsidian-adwaita-theme`](https://github.com/birneee/obsidian-adwaita-theme) by birneee.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-adwaita-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Adwaita** for the dark variant or **Adwaita Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
