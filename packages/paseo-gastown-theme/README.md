# paseo-gastown-theme

Gastown for [Paseo](https://paseo.sh), ported from the Obsidian theme [`dogwaddle/obsidian-gastown-theme.md`](https://github.com/dogwaddle/obsidian-gastown-theme.md) by dogwaddle.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-gastown-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Gastown**.

## Themes

This plugin contributes one `light`-mode `addTheme` variant derived from the upstream Obsidian palette.
