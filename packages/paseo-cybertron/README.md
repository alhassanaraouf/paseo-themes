# paseo-cybertron

Cybertron for [Paseo](https://paseo.sh), ported from the Obsidian theme [`nickmilo/Cybertron`](https://github.com/nickmilo/Cybertron) by nickmilo.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-cybertron
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Cybertron** for the dark variant or **Cybertron Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
