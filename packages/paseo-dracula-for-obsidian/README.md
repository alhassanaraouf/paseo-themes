# paseo-dracula-for-obsidian

Dracula for Obsidian for [Paseo](https://paseo.sh), ported from the Obsidian theme [`jarodise/Dracula-for-Obsidian.md`](https://github.com/jarodise/Dracula-for-Obsidian.md) by jarodise.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-dracula-for-obsidian
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Dracula for Obsidian** for the dark variant or **Dracula for Obsidian Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
