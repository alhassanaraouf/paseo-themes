# paseo-nier

Nier for [Paseo](https://paseo.sh), ported from the Obsidian theme [`exloseur3d/nier-theme`](https://github.com/exloseur3d/nier-theme) by exloseur3d.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-nier
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Nier** for the dark variant or **Nier Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
