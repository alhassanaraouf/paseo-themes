# paseo-ars-magna

Ars Magna for [Paseo](https://paseo.sh), ported from the Obsidian theme [`mediapathic/obsidian-arsmagna-theme`](https://github.com/mediapathic/obsidian-arsmagna-theme) by mediapathic.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-ars-magna
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Ars Magna** for the dark variant or **Ars Magna Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
