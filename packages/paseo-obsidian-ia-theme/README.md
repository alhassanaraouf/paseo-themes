# paseo-obsidian-ia-theme

obsidian_ia for [Paseo](https://paseo.sh), ported from the Obsidian theme [`rcvd/obsidian_ia`](https://github.com/rcvd/obsidian_ia) by rcvd.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidian-ia-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **obsidian_ia** for the dark variant or **obsidian_ia Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
