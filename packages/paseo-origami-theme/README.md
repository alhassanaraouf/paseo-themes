# paseo-origami-theme

Origami for [Paseo](https://paseo.sh), ported from the Obsidian theme [`7368697661/Origami`](https://github.com/7368697661/Origami) by kneecaps.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-origami-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Origami** for the dark variant or **Origami Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
