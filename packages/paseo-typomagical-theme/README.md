# paseo-typomagical-theme

Typomagical for [Paseo](https://paseo.sh), ported from the Obsidian theme [`hungsu/typomagical-obsidian`](https://github.com/hungsu/typomagical-obsidian) by hungsu.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-typomagical-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Typomagical** for the dark variant or **Typomagical Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
