# paseo-typora-vue

Typora-Vue for [Paseo](https://paseo.sh), ported from the Obsidian theme [`zekunc/Obsidian-Typora-Vue-Theme`](https://github.com/zekunc/Obsidian-Typora-Vue-Theme) by zekunc.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-typora-vue
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Typora-Vue** for the dark variant or **Typora-Vue Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
