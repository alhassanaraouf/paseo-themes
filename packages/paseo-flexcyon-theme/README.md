# paseo-flexcyon-theme

flexcyon for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bladeacer/flexcyon`](https://github.com/bladeacer/flexcyon) by bladeacer.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-flexcyon-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **flexcyon** for the dark variant or **flexcyon Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
