# paseo-sodalite

Sodalite for [Paseo](https://paseo.sh), ported from the Obsidian theme [`tomzorz/Sodalite`](https://github.com/tomzorz/Sodalite) by tomzorz.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-sodalite
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Sodalite** for the dark variant or **Sodalite Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
