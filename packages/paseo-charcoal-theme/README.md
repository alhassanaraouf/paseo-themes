# paseo-charcoal-theme

Charcoal for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bcdavasconcelos/Obsidian-Charcoal`](https://github.com/bcdavasconcelos/Obsidian-Charcoal) by bcdavasconcelos.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-charcoal-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Charcoal**.

## Themes

This plugin contributes one `dark`-mode `addTheme` variant derived from the upstream Obsidian palette.
