# paseo-prism

Prism for [Paseo](https://paseo.sh), ported from the Obsidian theme [`damiankorcz/Prism-Theme`](https://github.com/damiankorcz/Prism-Theme) by damiankorcz.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-prism
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Prism** for the dark variant or **Prism Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
