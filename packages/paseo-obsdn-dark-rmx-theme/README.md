# paseo-obsdn-dark-rmx-theme

Obsdn-Dark-Rmx for [Paseo](https://paseo.sh), ported from the Obsidian theme [`cannibalox/Obsdn-dark-rmx`](https://github.com/cannibalox/Obsdn-dark-rmx) by cannibalox.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsdn-dark-rmx-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsdn-Dark-Rmx** for the dark variant or **Obsdn-Dark-Rmx Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
