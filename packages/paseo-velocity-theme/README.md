# paseo-velocity-theme

Velocity for [Paseo](https://paseo.sh), ported from the Obsidian theme [`gonzalo-d-sales/obsidian-velocity`](https://github.com/gonzalo-d-sales/obsidian-velocity) by gonzalo-d-sales.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-velocity-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Velocity** for the dark variant or **Velocity Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
