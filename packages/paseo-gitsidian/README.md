# paseo-gitsidian

Gitsidian for [Paseo](https://paseo.sh), ported from the Obsidian theme [`ismailgunacar/gitsidian`](https://github.com/ismailgunacar/gitsidian) by ismailgunacar.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-gitsidian
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Gitsidian** for the dark variant or **Gitsidian Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
