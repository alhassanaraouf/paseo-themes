# paseo-atom-theme

Atom for [Paseo](https://paseo.sh), ported from the Obsidian theme [`kognise/obsidian-atom`](https://github.com/kognise/obsidian-atom) by kognise.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-atom-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Atom** for the dark variant or **Atom Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
