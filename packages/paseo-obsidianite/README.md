# paseo-obsidianite

Obsidianite for [Paseo](https://paseo.sh), ported from the Obsidian theme [`bennyxguo/Obsidian-Obsidianite`](https://github.com/bennyxguo/Obsidian-Obsidianite) by bennyxguo.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-obsidianite
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Obsidianite** for the dark variant or **Obsidianite Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
