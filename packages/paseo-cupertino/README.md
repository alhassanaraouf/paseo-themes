# paseo-cupertino

Cupertino for [Paseo](https://paseo.sh), ported from the Obsidian theme [`svnaxis/obsidian-cupertino`](https://github.com/svnaxis/obsidian-cupertino) by Alexis C.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-cupertino
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Cupertino** for the dark variant or **Cupertino Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
