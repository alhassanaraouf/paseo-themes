# paseo-wasp

Wasp for [Paseo](https://paseo.sh), ported from the Obsidian theme [`santiyounger/Wasp-Obsidian-Theme`](https://github.com/santiyounger/Wasp-Obsidian-Theme) by Santi Younger.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-wasp
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Wasp** for the dark variant or **Wasp Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
