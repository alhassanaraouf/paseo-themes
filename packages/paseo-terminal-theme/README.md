# paseo-terminal-theme

Terminal for [Paseo](https://paseo.sh), ported from the Obsidian theme [`zcysxy/Obsidian-Terminal-Theme`](https://github.com/zcysxy/Obsidian-Terminal-Theme) by zcysxy.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-terminal-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Terminal** for the dark variant or **Terminal Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
