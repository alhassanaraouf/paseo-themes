# paseo-yin-and-yang-theme

Yin and Yang for [Paseo](https://paseo.sh), ported from the Obsidian theme [`chetachiezikeuzor/Yin-and-Yang-Theme`](https://github.com/chetachiezikeuzor/Yin-and-Yang-Theme) by chetachiezikeuzor.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-yin-and-yang-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Yin and Yang** for the dark variant or **Yin and Yang Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
