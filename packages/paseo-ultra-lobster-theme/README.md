# paseo-ultra-lobster-theme

Ultra Lobster for [Paseo](https://paseo.sh), ported from the Obsidian theme [`7368697661/Ultra-Lobster`](https://github.com/7368697661/Ultra-Lobster) by kneecaps.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-ultra-lobster-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Ultra Lobster** for the dark variant or **Ultra Lobster Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
