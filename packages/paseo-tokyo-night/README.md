# paseo-tokyo-night

Tokyo Night for [Paseo](https://paseo.sh), ported from the Obsidian theme [`tcmmichaelb139/obsidian-tokyonight`](https://github.com/tcmmichaelb139/obsidian-tokyonight) by tcmmichaelb139.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-tokyo-night
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Tokyo Night** for the dark variant or **Tokyo Night Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
