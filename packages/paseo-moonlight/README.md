# paseo-moonlight

Moonlight for [Paseo](https://paseo.sh), ported from the Obsidian theme [`kartik-karz/moonlight-obsidian`](https://github.com/kartik-karz/moonlight-obsidian) by kartik-karz.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-moonlight
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Moonlight** for the dark variant or **Moonlight Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
