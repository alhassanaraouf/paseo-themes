# paseo-everforest

Everforest for [Paseo](https://paseo.sh), ported from the Obsidian theme [`0xglitchbyte/obsidian_everforest`](https://github.com/0xglitchbyte/obsidian_everforest) by 0xglitchbyte.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-everforest
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Everforest** for the dark variant or **Everforest Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
