# paseo-fancy-a-story

Fancy-a-Story for [Paseo](https://paseo.sh), ported from the Obsidian theme [`elsatam/obsidian-fancy-a-story`](https://github.com/elsatam/obsidian-fancy-a-story) by elsatam.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-fancy-a-story
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Fancy-a-Story** for the dark variant or **Fancy-a-Story Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
