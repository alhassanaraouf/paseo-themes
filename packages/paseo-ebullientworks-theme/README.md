# paseo-ebullientworks-theme

Ebullientworks for [Paseo](https://paseo.sh), ported from the Obsidian theme [`ebullient/obsidian-theme-ebullientworks`](https://github.com/ebullient/obsidian-theme-ebullientworks) by ebullient.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-ebullientworks-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Ebullientworks** for the dark variant or **Ebullientworks Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
