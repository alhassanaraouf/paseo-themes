# paseo-things

Things for [Paseo](https://paseo.sh), ported from the Obsidian theme [`colineckert/obsidian-things`](https://github.com/colineckert/obsidian-things) by colineckert.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-things
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Things** for the dark variant or **Things Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
