# paseo-ono-sendai

Ono Sendai for [Paseo](https://paseo.sh), ported from the Obsidian theme [`cannibalox/ono-sendai_obsdn`](https://github.com/cannibalox/ono-sendai_obsdn) by cannibalox.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-ono-sendai
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Ono Sendai** for the dark variant or **Ono Sendai Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
