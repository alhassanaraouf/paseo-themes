# paseo-solarized

Solarized for [Paseo](https://paseo.sh), ported from the Obsidian theme [`harmtemolder/obsidian-solarized`](https://github.com/harmtemolder/obsidian-solarized) by harmtemolder.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-solarized
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Solarized** for the dark variant or **Solarized Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
