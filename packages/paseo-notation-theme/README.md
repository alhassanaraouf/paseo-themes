# paseo-notation-theme

Notation for [Paseo](https://paseo.sh), ported from the Obsidian theme [`deathau/Notation-for-Obsidian`](https://github.com/deathau/Notation-for-Obsidian) by deathau.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-notation-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Notation** for the dark variant or **Notation Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
