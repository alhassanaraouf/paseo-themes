# paseo-material-ocean-theme

Material Ocean for [Paseo](https://paseo.sh), ported from the Obsidian theme [`dragonwocky/obsidian-material-ocean`](https://github.com/dragonwocky/obsidian-material-ocean) by dragonwocky.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-material-ocean-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Material Ocean**.

## Themes

This plugin contributes one `dark`-mode `addTheme` variant derived from the upstream Obsidian palette.
