# paseo-willemstad

Willemstad for [Paseo](https://paseo.sh), ported from the Obsidian theme [`tingmelvin/willemstad-x`](https://github.com/tingmelvin/willemstad-x) by tingmelvin.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-willemstad
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Willemstad** for the dark variant or **Willemstad Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
