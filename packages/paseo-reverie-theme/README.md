# paseo-reverie-theme

Reverie for [Paseo](https://paseo.sh), ported from the Obsidian theme [`santiyounger/Reverie-Obsidian-Theme`](https://github.com/santiyounger/Reverie-Obsidian-Theme) by Santi Younger.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-reverie-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **Reverie** for the dark variant or **Reverie Light** for the light variant.

## Themes

This plugin contributes two `addTheme` variants derived from the upstream Obsidian palette.
