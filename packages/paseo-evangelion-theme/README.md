# paseo-evangelion-theme

evangelion for [Paseo](https://paseo.sh), ported from the Obsidian theme [`xero/evangelion.obsidian`](https://github.com/xero/evangelion.obsidian) by xero.

## Install

```bash
paseo plugin install npm:@alhassanaraouf/paseo-evangelion-theme
```

## Activate

1. Open **Settings \u2192 Appearance**.
2. Set **Theme** to **evangelion**.

## Themes

This plugin contributes one `dark`-mode `addTheme` variant derived from the upstream Obsidian palette.
